## 4. Fix pnpm 10 build scripts (`02c93ec`)

### Error:

```
Ignored build scripts: @prisma/engines@7.5.0, prisma@7.5.0, sharp@0.34.5, unrs-resolver@1.11.1
```

Vercel uses pnpm 10.x, which blocks all dependency postinstall/preinstall scripts unless explicitly whitelisted. Without these scripts running, Prisma cannot download its query engine binary and Sharp cannot set up native image processing.

## 5. Remove empty 0-byte files (`ee6a266`)

### Error:

```
Type error: File '/vercel/path0/app/docs/page.tsx' is not a module.
```

Next.js requires every `.tsx`/`.ts` file in the `app/` directory to export at least a default component. Empty 0-byte files have no exports and are rejected.

## 6. Lazy-load Resend client (`99a3e8d`)

### Error:
```
Error: Missing API key. Pass it to the constructor `new Resend("re_123")`
```

After commits `a135465` through `ee6a266` resolved all TypeScript and empty-file errors, the build crashed during **"Collecting page data"**. `lib/email.ts` created the Resend client at the top level of the module. During `next build`, Next.js imports modules to analyze page data, even API route modules. Since `RESEND_API_KEY` is a runtime-only secret (not set during build), `new Resend(undefined)` threw.

# Note

After deploying, set `RESEND_API_KEY` in Vercel's **Settings → Environment Variables** for email functionality to work at runtime. The build succeeds without it, but `sendPasswordResetEmail()` and `send2FACode()` will fail if the key is missing.
