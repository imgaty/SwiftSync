# Argent - File Review Checklist

Last refreshed: 2026-06-08

This checklist tracks source-owned files only. Generated, dependency, build, local-agent, and local-environment artifacts are intentionally excluded.

## Excluded From Review

- `node_modules/` - package manager install output
- `.next/` and `tsconfig.tsbuildinfo` - build/typecheck output
- `lib/generated/` - generated by `prisma generate` during build
- `.agents/`, `commits/`, `codex-review-reports/` - agent output and commit documentation artifacts
- `.env*`, `.vercel/`, `.venv/`, `.superpowers/`, `.claude/` - local environment/tooling state
- `.DS_Store` - operating system metadata
